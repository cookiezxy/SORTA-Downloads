# SORTA 薯塔

SORTA 是 Windows 上的离线磁盘空间工具。C 盘空间紧张时，可以查看主要占用、了解处理建议，再确认要清理的项目。

[下载 Windows x64 安装包](https://github.com/cookiezxy/SORTA-Downloads/releases)

## 安装

1. 在发布页下载 `SORTA-0.1.10-Setup-win-x64.exe`。Win10 和 Win11 共用一个安装包。
2. 如果已经安装旧版，关闭 SORTA，在 Windows「应用」设置中卸载旧版。
3. 运行安装程序。点「浏览」可以选择本机固定盘上的安装位置。选择 D 盘时，目标会显示为 `D:\SORTA`。

安装包当前未签名，Windows 可能弹出安全提示，部分由单位管理的设备可能拦截。发布页的 SHA-256 文件可用于核对下载内容。

## 可以做什么

- 查看 C 盘主要占用和需要判断的大文件。
- 预览清理清单，确认后清理选中的临时文件，并查看实测空间变化。
- 在两块本地 NTFS 卷之间归档单个文件。验证副本并确认释放原件后，可以通过历史记录恢复。
- 调整和恢复 Windows 下载文件夹，以及从 SORTA 启动 Edge 时使用的专用缓存位置。
